
# Digital Medication Tracker

## Project Description

Digital Medication Tracker is a web application developed using Python and Streamlit for my Python Fundamentals Project 1.

The application helps users organize medication information, manage daily schedules, track medication inventory, and visualize medication data through an interactive dashboard.

## Features

- **Add Medication:** Add medications with their names, active ingredients, dosage frequencies, instructions, urgency levels, and categories.
- **Interaction Check:** Search for medications containing the same active ingredient.
- **Daily Schedule:** Select medications and save their scheduled times.
- **Inventory:** View and manage medication stock.
- **Dashboard:** Visualize medication information using charts and statistics.
- **CSV Upload:** Upload medication records from a CSV file.

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn
- CSV files for data storage
